# 目录与校验格式

一个盘号目录对应一份准备刻录的光盘内容。批次目录名可由“编号＋日期＋主题”组成，也可完整输入，格式均为 `B01_YYYY-MM-DD_Title`，编号范围 01–99。同一张盘追加新批次时，沿用盘号并建立 `B02`。是否能续写光盘由刻录方式和盘片状态决定，本程序只准备硬盘目录。

```text
ARC_BDR25_001/
├── DISC_INFO.txt
├── B01_2026-10-06_Photos/
│   ├── ABOUT.txt             # 可选
│   ├── SHA256SUMS.txt
│   └── DATA/
└── B02_2026-10-20_Documents/
    ├── SHA256SUMS.txt
    └── DATA/
```

`DISC_INFO.txt` 是 UTF-8 文本，记录盘号、计划使用的介质、创建日期、目录约定、校验算法和建议卷标。手动填写的制造商 MID 会写在 `MID:` 行；未填写则省略这一行。程序不会在已有盘号目录中重写该文件。光驱型号和 Windows 报告的容量只在界面中临时显示。

每个批次的 `SHA256SUMS.txt` 也是 UTF-8 文本。每行依次为小写的 64 位 SHA-256 十六进制值、两个空格、相对于批次目录的文件路径。路径用 `/` 分隔，例如：

```text
2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824  DATA/hello.txt
```

程序递归遍历 `DATA/` 中的所有子目录，对每个普通文件生成一行。有 `ABOUT.txt` 时，也为它生成一行。没有 ABOUT 的批次须在界面中明确勾选“不写 ABOUT.txt”。空文件夹不会出现在清单中；`SHA256SUMS.txt` 和盘根目录的 `DISC_INFO.txt` 也不在清单里。

读回校验会检查清单格式，重新计算列出文件的哈希，并指出缺失或多出的文件。它拒绝 `DATA/` 内的符号链接、Windows 重解析点和云盘占位文件。通过校验说明所选目录中的文件与其中的清单一致；如需保存盘号、介质和 MID 的可信记录，请把 `DISC_INFO.txt` 和清单另存到硬盘索引。校验不会检测空目录或盘片的物理错误率。

若发现已刻录盘上的 `DISC_INFO.txt` 有误，修正本地记录并注明盘上原值。尤其不要为更正一行元数据而随意在一次写入光盘上追加会话：没有正确导入旧目录的新会话，可能使资源管理器看不到先前的文件。
